- **Power BI & Business Intelligence**: Designed a 5-page Power BI dashboard featuring a Fortune-500 corporate theme and a library of 25+ custom DAX measures (`Total Sales`, `Net Profit Margin %`, `YoY Growth`, `CLV`).
- **REST API Backend & Web UI**: Developed a FastAPI REST server with OAuth2 JWT Access/Refresh tokens and Role-Based Access Control (`Admin`, `Manager`, `Analyst`); built a responsive Glassmorphism React single-page UI with interactive Chart.js visualizations.
- **DevOps, Security & CI/CD**: Containerized platform using Docker & Docker Compose; authored 17 automated Pytest cases covering unit, integration, API, and ML tests; established GitHub Actions CI/CD pipeline for automated testing and container builds.
